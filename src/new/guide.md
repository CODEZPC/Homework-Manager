## 重构架构

原项目是单文件为主的紧耦合架构（~1200 行 main.py + 循环导入），重构后采用清晰的 **MVC 三层分离架构**：

```
src/new/
├── __init__.py              # 包入口
├── app.py                   # 应用主控制器（Application 类）
├── config.py                # 全局配置常量（颜色/尺寸/路径/版本）
├── models/
│   ├── __init__.py
│   └── data_store.py        # JSON 数据读写层（线程安全）
├── services/
│   ├── __init__.py
│   ├── time_analyzer.py     # 时间解析与排序
│   ├── homework_service.py  # 作业 CRUD 业务逻辑
│   ├── updater.py           # 自动更新（状态机模式）
│   ├── classisland.py       # ClassIsland 集成
│   ├── lock_manager.py      # 进程锁
│   └── data_migration.py    # 数据版本迁移
└── views/
    ├── __init__.py
    ├── root_window.py       # Tk 根窗口管理
    ├── main_screen.py       # 主界面（Canvas + 按钮栏 + 信息栏）
    ├── homework_dialog.py   # 作业添加/编辑对话框
    ├── menu_dialog.py       # 科目管理面板
    └── help_dialog.py       # 帮助手册（树形导航）
```

## 关键改进

| 方面 | 原架构 | 重构后 |
|------|--------|--------|
| **模块依赖** | 循环导入（menu.py→`main`，help.py→`main`） | 单向依赖，依赖注入 |
| **全局变量** | `tk`、`COLOR` 跨模块共享 | 通过构造函数注入 |
| **UI/逻辑分离** | 混杂在 `HomeworkTool` 类中 | View 纯 UI，Service 纯逻辑 |
| **数据访问** | 散落各处的 `json.load/dump` | 统一 `DataStore`，线程安全 |
| **错误处理** | 大量裸 `except: pass` | 指定异常类型 + 日志输出 |
| **配置管理** | 魔术数字散布 | 集中到 `config.py` |
| **更新状态** | 字符串散落 | `UpdateStatus` 常量类 + 回调 |
| **类型注解** | 无 | 完整的 `typing` 支持 |
